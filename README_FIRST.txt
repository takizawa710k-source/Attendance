QR登校管理 v17：スマホQR＋学生証バーコード

【追加機能】
教職員画面に「学生証バーコード受付」を追加しました。
学生証に入れた学籍番号を、PC接続のバーコードリーダーで読み取ります。
スマホQRと同じ「1日1回の登校記録」に登録します。
同じ日に両方で登録しても、最初の登校時刻を保持します。
顔写真・氏名・クラス・登校時刻・確認済み表示に対応します。
複数学生の連続読み取りは順番に処理します。
このPCの直近20件の結果を表示します（画面を閉じると履歴表示は消えますが、登校記録はDBに残ります）。

【PCでの使い方】
1. USBまたはBluetoothのリーダーをPCに接続します。
2. メモ帳で読み取り、学籍番号が正しく入力されることを確認します。
3. リーダーを「USB HID／キーボード入力」「読取後にEnter」に設定します。
4. 学校の出席Webの教職員画面へログインします。
5. 「学生証バーコード受付」を開き、学籍番号欄にカーソルを置きます。
6. 学生証を順に読み取ります。必要なら学籍番号を手入力して登録できます。
受付専用PCではこの画面を前面にしてください。先頭の0も学籍番号の一部として照合します。
通信エラーが出た学生は再読み取りしてください。二重登録にはなりません。
「在籍学生が見つかりません」と出た場合は、バーコードの文字列と名簿を確認してください。
この画面の履歴はこのPCだけの受付履歴です。全体の登校状況は「登校一覧へ」で確認します。

【Railwayへの更新（Windows PowerShell）】
保存されていたv16（2026年9月2日版）を基に修正しました。
その後に別の修正を加えた場合は、その最新版との比較が必要です。
更新前に現在のプログラムと登校データをバックアップしてください。
本パッケージは本番へまだデプロイしていません。

既存のプログラムフォルダへ、このZIP内の app.py を上書きしてください。
（他の独自修正がない場合。本変更で変わる実行ファイルはapp.pyだけです。）
現在使っているフォルダで、前回と同じRailway CLIを実行してください。
例：
  cd "C:\railway\M1_QR_Attendance_v16_daily_cloud"
  C:\railway\railway.exe up --service attendance-web

未リンクの場合のみ先に実行：
  C:\railway\railway.exe link
  My Projects -> heartfelt-magic -> production

既存の attendance-web に更新してください。
Volume /app/data、DATA_DIR=/app/data、TEACHER_PASSWORDを維持してください。
データベースの構造変更はありません。既存の名簿・顔写真・登校記録をそのまま利用します。

- 未登録／非在籍／不正な学籍番号の拒否と先頭0の保持
- 登校一覧の人数、既存の手動登録
- 連続入力の待ち行列、登録済み／エラー表示、表示文字列のエスケープ
