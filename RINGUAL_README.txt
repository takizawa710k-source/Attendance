RINGUAL Excel 一括出力 (v15)

教師トップ画面:
  「RINGUAL一括出力」から、全クラス・複数日を1ファイルに出力します。

初回:
  1. RINGUALですでに登録済みの最終日を設定します。
  2. その翌日が次回の自動開始日になります。

通常運用:
  1. 「RINGUAL一括出力」を開く。
  2. 前回登録日の翌日から、今回指定した終了日までをExcel出力。
  3. RINGUALにアップロード。
  4. 正常に登録できたことを確認後、「この日まで登録完了として記録」を押す。
  5. 次回は、その翌日から自動的に出力。

注意:
  Excelを出力しただけでは、RINGUAL登録済み日は進みません。
  必ずRINGUALへのアップロード成功後に「登録完了」を押してください。

出力内容:
  - 全クラス
  - 前回登録日の翌日～指定した終了日（連続した日付）
  - 各日 1～4限
  - 状態、遅刻早退時間（分）、入退室時刻、出欠メモ

RINGUAL変換:
  出席 -> 出
  欠席 -> 欠
  遅刻 -> 遅
  早退 -> 早
  公欠 -> 公
  出席停止 -> 停

保存:
  前回RINGUAL登録済み日は attendance.db の app_settings に保存されます。
  Railway Volume (/app/data) に保存されるため、再デプロイ後も残ります。
